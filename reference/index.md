# Package index

## Main models

- [`schint_cell()`](https://LidaWangPSU.github.io/scHINT/reference/schint_cell.md)
  : Cell-level G×Cell-State heritability model
- [`schint_sample()`](https://LidaWangPSU.github.io/scHINT/reference/schint_sample.md)
  : Sample-level G×Cell-Type heritability model
- [`schint_pert()`](https://LidaWangPSU.github.io/scHINT/reference/schint_pert.md)
  : Perturbation heritability with cell-state or cell-type interaction

## Genotypes and GRMs

- [`make_grm()`](https://LidaWangPSU.github.io/scHINT/reference/make_grm.md)
  : Build a genomic relationship matrix from genotypes
- [`split_snps()`](https://LidaWangPSU.github.io/scHINT/reference/split_snps.md)
  : Split SNPs into groups (for multiple GRMs)
- [`read_plink()`](https://LidaWangPSU.github.io/scHINT/reference/read_plink.md)
  : Read a PLINK binary fileset as a dosage matrix
- [`select_cis_snps()`](https://LidaWangPSU.github.io/scHINT/reference/select_cis_snps.md)
  : Select cis SNPs around a gene
- [`read_grm_bin()`](https://LidaWangPSU.github.io/scHINT/reference/read_grm_bin.md)
  [`write_grm_bin()`](https://LidaWangPSU.github.io/scHINT/reference/read_grm_bin.md)
  : Read / write a GCTA binary GRM

## Simulation and example data

- [`simulate_geno()`](https://LidaWangPSU.github.io/scHINT/reference/simulate_geno.md)
  : Simulate genotypes with local LD
- [`simulate_schint()`](https://LidaWangPSU.github.io/scHINT/reference/simulate_schint.md)
  : Simulate cell-level and sample-level expression for the example data
- [`simulate_pert()`](https://LidaWangPSU.github.io/scHINT/reference/simulate_pert.md)
  : Simulate perturb-seq-like data for the perturbation heritability
  model
- [`schint_example`](https://LidaWangPSU.github.io/scHINT/reference/schint_example.md)
  : Example data for scHINT
- [`schint_pert_example`](https://LidaWangPSU.github.io/scHINT/reference/schint_pert_example.md)
  : Example perturb-seq data for scHINT
